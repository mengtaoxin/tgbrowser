# tgbrowser

tgbrowser is a self-hosted browser service you run yourself instead of relying on a hosted browser-as-a-service.

It starts and stops real Chromium browsers on demand, so your automation (or a person watching along) can open pages, keep signed-in profiles across runs, and step in when something needs a human—login, CAPTCHA, or judgment.

The point is a familiar “create a session, connect, then stop” control plane for browser work, under your own roof.
